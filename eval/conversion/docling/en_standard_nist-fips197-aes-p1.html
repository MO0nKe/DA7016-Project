4.1 Addition in GF(2 8 )

In order to add two elements in the fnite feld GF(2 8 ), the coeffcients of the polynomials that represent the elements are added modulo 2 (i.e., with the exclusive-OR operation, denoted by ⊕), so that 1⊕ 1 = 0, 1⊕ 0 = 1, and 0 ⊕ 0 = 0.

Equivalently, two bytes can be added by applying the exclusive-OR operation to each pair of corresponding bits in the bytes. Thus, the sum of {a7 a6 a5 a4 a3 a2 a1 a0} and {b7 b6 b5 b4 b3 b2 b1 b0} is {a7 ⊕ b7 a6 ⊕ b6 a5 ⊕ b5 a4 ⊕ b4 a3 ⊕ b3 a2 ⊕ b2 a1 ⊕ b1 a0 ⊕ b0}. (In Section 5.1.4, this defnition is extended to words.)
